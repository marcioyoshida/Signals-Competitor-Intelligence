Feed priorizado por ameaça

Cada cartão reúne sinais de várias fontes (as “lentes”) sobre a mesma entidade e traz o link de cada fonte. O nível de ameaça é uma estimativa que combina quantas fontes e quão relevantes são.

Revisão de entidades

Sugestões automáticas de vínculo entre entidades (ex.: mesmo controlador no QSA). Nada é mesclado automaticamente — cada proposta precisa de confirmação humana.

O nível de ameaça é uma estimativa heurística (não é um modelo validado). Cada afirmação tem link para a sua fonte.

Cobertura & Monitor

Cada indústria é um add-on de assinatura. Os números resumem o período; abra uma indústria para ver o pico de ameaça de cada entidade.

Pontos Cegos

Perguntas dentro do escopo que a base ainda não responde. Remediar corrige o que é seguro (curadoria/atributos do registro) e reverifica; o que exige nova fonte vira issue no GitHub.

Macro · Copom & Focus

Contexto macro do mercado (BCB): decisão do Copom / Selic e as expectativas do Relatório Focus. Sinais amplos de mercado — não são de um concorrente específico.
