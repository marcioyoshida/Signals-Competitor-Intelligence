## Source expansion (richer, more sustained narratives)

Current lenses are mostly **structured filings + numbers** (CVM funds/ofertas,
IF.data, Pix, juros, autorizações, SEC 6-K, CVM inf_diário). They carry *what*
happened but little *why it matters*, so narratives read factual-but-thin. The
gap is **qualitative / strategic** signal. Rank candidates by **citation
authority** (the product's moat) × **strategic richness**, and respect the
CLAUDE.md legal rules (government first; public web logged-out + robots.txt;
social/employment only via licensed aggregators — never scrape LinkedIn).

Priority order:

1. **CVM/B3 material facts** — "Fatos Relevantes" & "Comunicados ao Mercado" via
   CVM RAD / B3. Companies' own official disclosures of M&A, product launches,
   results guidance, leadership. Strategic **and** authoritative **and** zero
   legal risk. Biggest narrative-quality gain; extends the existing SEC/CVM lens.
   *(Verify live schema before wiring — CLAUDE.md "no invented API schemas".)*
2. **Diário Oficial da União (in.gov.br)** — SUSEP acts, **CADE** decisions,
   sanctions, appointments, concessions. Opens the **insurance** sub-vertical and
   M&A signals. Already flagged "deferred" in the plan.
3. **CADE (antitrust)** — merger reviews/approvals = competitor consolidation,
   early. Public, citable.
4. **SUSEP** — insurance regulator; fills the insurer sub-vertical.
5. **Trade press** (Valor, Brazil Journal, NeoFeed, Pipeline, InfoMoney) — high
   strategic color, but paywalls/ToS → via a **licensed news API or RSS
   headline+link**, summarize + cite the URL, never full-text scrape.
6. **Company IR / press pages** — logged-out, robots-respecting; official
   launches/partnerships cited to the source page.
7. **Hiring signals** — only via a licensed aggregator (People Data Labs /
   Explorium); never scraped LinkedIn.

Deprioritized: **X/Twitter** — weak citations for a regulated buyer, noisy, and
the API is now costly; revisit later for *official* competitor accounts only.

These complement (not replace) **real threat scoring** and **emit-on-change**:
strategic events (an M&A filing, a launch) should outscore a routine fund
registration, which is what makes the feed read as prioritized intel.

## Quiet-fintech radar (new-entrant detection)

BCB-regulated fintechs must appear in the "instituições em funcionamento"
registry when authorized — so a **registry diff** catches even quietly-registered
entrants (~24h, no press needed). This is the `new_entrants` lens
(`bcb_autorizacoes` + `detect_new`); it catches the **unknown** entrants a
watchlist can't. Complement: known names → watchlist/aliases (Creditas,
RecargaPay, Neon, InfinitePay/CloudWalk, Nomad — add brand **and** legal names;
Nomad is a blind spot, US-facing, thin BR footprint → needs trade press/IR).

- **Shipped 2026-08-16 — license classification.** `classify_license` maps
  SEGMENTO → compact classes (IP, SCD, SEP, SCFI, microcrédito, banco, …) with an
  `is_fintech` flag; scoring refines the entrant signal by class
  (`ENTRANT_CLASS_WEIGHT`) so a new SCD/IP outranks a new consórcio/cooperativa.
- **Shipped 2026-08-16 — Receita Federal CNPJ (QSA) enrichment.**
  `src/ingest/receita_cnpj.py`: the registry gives an 8-digit CNPJ raiz →
  reconstruct the matriz (raiz + 0001 + DV) → BrasilAPI (public, no key) for
  `nome_fantasia` (brand) + `qsa` (controllers). New entrants now read
  "NDD INSTITUICAO DE PAGAMENTO LTDA (NDD PAY) — Instituição de Pagamento.
  Controlador: NDD HOLDING FINANCEIRA LTDA." Enriches only new entrants (cap
  ONCA_RECEITA_MAX=15), caches by raiz, own wall-clock budget, degrades
  gracefully. Schema verified live (2026-08-16).
- **Shipped 2026-08-16 — link entrants to known parents.**
  `entities.known_parents` resolves an entrant's QSA controllers against the
  known-entity aliases; a new fintech controlled by a known player (e.g. a new
  SCD controlled by NU HOLDINGS → `nubank`) now **clusters into that parent's
  narrative + Entity Watch**, and the entrant reads "… Vinculado a concorrente
  conhecido: Nubank." Self-links excluded. Optional future: corroborate with
  Diário Oficial authorization atos.
- **Limits (honest):** BCB has no clean *pending-application (pleito)* feed, so
  authorization-in-operation is the earliest reliable public catch; daily cadence;
  dormant registrations disambiguated by Pix-participation activity.

## Product enhancements (decided)

- **Real, configurable threat scoring** — replace the placeholder heuristic
  (saturates at ~1.0). Prerequisite for trustworthy ranking, alerts, briefings.
- **Auto-generated cited briefings** (PDF/PPTX/email) — leadership-ready output;
  the killer corporate feature, uniquely enabled by the citation engine.
- **Multichannel alerts** (email / Slack / Teams / WhatsApp; Web Push) gated on
  real scoring; PWA before any native app. Keep AWS Marketplace as the B2B channel.
- **Accounts + workspace** (Cognito) → annotations, assign/status, relevance
  feedback, watchlists, entity dossiers, audit trail.
